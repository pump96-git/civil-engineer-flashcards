# 토목기사 플래시카드

토목기사 시험 준비용 모바일 우선 플래시카드 웹앱입니다.

## 실행

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다. 로컬 서버나 배포 주소에서 열면 홈 화면 추가와 오프라인 캐시도 동작합니다.

## 주요 기능

- 과목별 분류: 측량학, 수리학·수문학, 토질역학, 응용역학, 철근콘크리트, 상하수도
- 앞면/뒷면 플래시카드
- 카드 추가, 편집, 삭제
- 분수, 제곱, 아래첨자, 루트, 그리스 문자 입력 버튼
- MathJax 기반 수식 표시
- 알았어/다시 보기 학습 흐름
- 에빙하우스식 반복 간격: 오늘, 1일, 3일, 7일, 14일, 30일, 60일
- 오늘 학습 장수와 오늘 복습 카드 수 표시

## 저장 방식

카드는 브라우저 `localStorage`에 저장됩니다. 같은 기기와 같은 브라우저에서 다시 열면 유지됩니다.
